Going traceless removes one Cartan direction and narrows the BPS window by exactly one, as Chen (2.17) predicts. Result: **width $=\mathrm{rank}(G)+1$**, so **concentration $\iff\mathrm{rank}(G)\le2$**. $su(3)$ (rank 2) **does** concentrate — window $\{11,12,13\}$, one degree per class, $h=9,18,9$, the $1{:}2{:}1$ profile — and is BPS-identical to $u(2)$, the other rank-2 model and the source of Chen's $N=2$ evidence. $su(4)$ (rank 3) fails, width 4, $h=13,81,81,13$. So $su(N)$ rescues $N=3$ and nothing beyond: the window tracks the rank while the grading period is pinned at $q=3$, and large $N$ is large rank. Exact two-prime ranks; enumeration validated against $\binom{p(N^2-1)}{k}$. Caveat: maximal weight only, seven models.
